# Task 013 – Feinschliff nach dem Bühnenbild

**Status:** umgesetzt (2026-10-27), wartet auf die Abnahme des Eigentümers auf dem iPhone.
**Bezug:** [Task 012](012-buehnenbild-neu.md)

Die Wünsche des Eigentümers aus dem Abend des 27. Oktober, nach dem neuen Bühnenbild. Abgehakt ist, was gebaut, getestet (Screenshots oder Bildfolgen), gepusht und auf dem iPhone installiert ist. „Abnahme“ heißt: nur noch am Gerät ansehen.

## App

- [x] Startseite: Werwolf groß hinter dem Schriftzug, beide als Wellpappe in eigenem Takt drehend, die Pfote liegt vor den Buchstaben und bleibt auf ihrem Buchstaben (beide drehen um den Griffpunkt). Abnahme: kein Durchglitchen mehr.
- [x] Wischen: das Bühnenbild schwenkt, die Kulissen sind ein Panorama über drei Seiten, nichts gespiegelt.
- [x] Neigen: Parallaxe gedämpft (ein Drittel, langsamer).
- [x] Name bleibt gespeichert, Raum-Wiederherstellen nur bei laufender Partie, Schnellbeitritt zum letzten Raum in der Nähe.
- [x] Ein selbst geschlossener Raum erscheint nicht mehr zum Beitreten. Abnahme.
- [x] Tastatur schiebt das Namensfeld hoch, statt den Bildschirm zu verkleinern.
- [x] App-Einstellungen direkt auf der rechten Startseite; Sprache als Flagge oben rechts.
- [x] Menüs und Auswahlknöpfe überall als Plaketten (Messingrand, Buchserife, gewählte Option in Laternenorange). Abnahme: Schatten des Flaggen-Menüs.
- [x] Lesbarkeit: jeder Text direkt auf dem Bühnenbild hat eine weiche Nacht-Unterlage.
- [x] Lobby: Seiten Figur, Tisch (Einladung mit QR oben, Tischkreis, Spielübersicht) und für den Spielleiter die Spieleinstellungen als Seite, jeder Abschnitt auf einer Plakette. Der Spielleiter landet auf der Tisch-Seite. Abnahme: QR-Code beim Raum-Eröffnen.
- [x] Figurenwahl: große Karten, drei pro Reihe auf dem Handy; Wechsel genau an der Kante (90°); leiserer Kartenklang.
- [x] Figurenwahl: die gewählte Figur fliegt mit einer Drehung aus ihrer Karte nach oben, die Seite scrollt mit, die alte verlässt die Bühne nach oben und gleitet in ihre Karte zurück. Abnahme: die Animation selbst (im Test nicht darstellbar).
- [x] App-Icon als Collage.

## Website

- [x] Szenen blenden ineinander über (Überblendung statt dunklem Streifen), Mond und hängende Teile beginnen unter der Überblendung. Abnahme.
- [x] Mobil: nichts scrollt mehr seitlich, Kulissen richten sich nach der Bildschirmhöhe, Vorhänge hängen von oben.
- [x] Lesbarkeit der Überschriften, Finale dunkler getönt, Footer setzt die Nacht fort.
- [x] Download-Seite zeigt die Download-Zahlen groß im Bühnenstil.
- [x] Texte sprachlich überarbeitet (Humanizer).
