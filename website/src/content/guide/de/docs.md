## Eine Runde in einer Minute

1. **Einer eröffnet den Raum.** Ein Handy tippt auf „Raum eröffnen“ und wird damit zum Gastgeber. Es spielt ganz normal mit.
2. **Alle anderen kommen dazu.** Sie tippen auf „Raum beitreten“ und dann auf den Raum, der dort erscheint, oder scannen den QR-Code vom Gastgeber.
3. **Jeder wählt eine Figur.** Sie ist nur euer Aussehen am Tisch und verrät nichts über eure Rolle.
4. **Die Rollen werden geheim verteilt.** Jeder schaut allein auf sein Handy: Dorf oder Werwolf?
5. **Nachts tippen alle.** Die Werwölfe wählen ein Opfer, die Seherin blickt in jemanden hinein, alle anderen zählen Schäfchen. Von außen sieht das bei allen gleich aus.
6. **Tagsüber wird geredet, dann abgestimmt.** Ihr diskutiert am Tisch, gezählt wird in der App. Das geht so lange, bis das Dorf alle Werwölfe gefunden hat oder die Werwölfe das Dorf überrannt haben.

Ausführlich steht das unter [So spielt ihr](/docs/so-spielt-ihr/).
